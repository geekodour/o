## Personal lexicon {#personal-lexicon}

These are words, phrases and private meanings that recur across my notes. Some
are deliberate coinages, while others are existing words that I use as names
for specific parts of my life and systems. Unlike the collected jargon below,
these are Hrishi-isms.


### Core terms {#core-terms}

**ICCES loop**
: My non-linear workflow for turning curiosity into output:
    Inspiration, Capture, Consume, Execute and Share. The loop has no fixed start
    or end. See [ICCES Loop]({{< relref "o#icces-loop" >}}).

**Idea Monkeysphere**
: My map of subjects I want to understand, why I want to
    understand them and roughly how deep I want to go. It is intentionally not a
    syllabus. See [Idea Monkeysphere]({{< relref "monkeysphere" >}}).

**Komputeer Ussah**
: Computer enthusiasm; the playful name for the part of my
    toolchest concerned with using and enjoying physical computers.

**Bespoke Garbage**
: Custom, strange and imperfect projects made because I
    need them, want to learn from them or simply enjoy building them.

**right trash**
: A project can be trash and still be the right trash: useful,
    interesting, measurable or aligned with what I want to do.

**toolchest**
: A curated arsenal of tools. The primary toolchest contains
    tools and workflows I actively use; the secondary toolchest is the candidate
    tool and bookmark backlog whose ideal state is empty.

**Plumber Manual**
: My emergency Linux and sysadmin runbook for inspection,
    recovery, troubleshooting, networking and operational practices.

**Snipes**
: Questions with which I nerdsnipe myself and keep running in the
    back of my mind. See [Snipes]({{< relref "snipes" >}}).

**Gandhi ₹**
: My money-game document: income, financial independence, funding
    and earning without surrendering autonomy. See [Gandhi ₹]({{< relref "gandhi" >}}).

**Deathnote**
: Public end-of-life instructions and information useful if I
    "fall in love with death". See [Deathnote]({{< relref "when_i_die" >}}).

**Gears**
: My personal hardware, software, lifestyle and operational setup
    inventory. See [Gears]({{< relref "gears" >}}).

**Locus**
: The index of personal systems, sites, notes and repositories that
    I host publicly. See [Locus]({{< relref "locus" >}}).

**Digital Warrior**
: My collection of practical privacy, security, activism,
    journalism and archival resources.

**HB-series syllabus**
: My private numbering scheme for goal-shaped syllabi:
    _Remove database fear_, _Become spiderman_, _Hello Beep Boop HCI_ and so on.

**cached/discounted version of me**
: A personal homepage as an incomplete,
    asynchronously available representation of me.

**self-nerdsnipe**
: Becoming consumed by a technical question I posed to
    myself.

**brain bootloop**
: The frozen state caused by an expensive context switch.

**money plugs**
: Income-producing hooks attached to work I already want to do.

**passive income mafia**
: A deliberately exaggerated network of passive
    income streams.

**wild thought pool**
: A reservoir of speculative, silly or unconstrained ideas.

**brain capabilities maxxing**
: Deliberately upgrading memory, calculation
    and general cognitive ability.

**serious without a suit**
: Doing serious work while rejecting unnecessary
    corporate formality.

**No knowledge, no worries**
: Entering an unfamiliar domain confidently
    because I expect to learn it quickly.

: Intentionally decommissioned.

: Abruptly abandoned.

: Dead software still floating around online.

**dog slow**
: Progressing exceptionally slowly.

: Affectionate, self-deprecating terms for my output rather
    than reasons not to make it.

## Jargons {#jargons}

This is a growing list of words that I came across and I thought to myself, I'll probably forget about this but it's nice, better keep a note somewhere. This list is domain agnostic.

-   **Slashdot effect**: Also known as slashdotting, occurs when a popular website links to a smaller website, causing a massive increase in traffic.
-   **HugOps**: It is a way to celebrate the human, empathetic side of building, shipping, and running software.
-   **Watchdog timer** : Used in Mars Exploration Rover (MER) 🚀 See also Dead man's switch.
-   **Unsolicited daemon** : A daemon process that sleeping for a long time, legends say it can sometime have 0 RES memory.
-   **opcode** : abbreviated from operation code, it is basically the portion of a machine language instruction that specifies the operation to be performed. Apart from ISAs, bytecode specifications also use opcodes.
-   **exploratory programming** : programming that is not actually solving a problem but primarily aims at finding how things are working, btw the name is self explanatory ;)
-   **tarpits** : a network service that intentionally inserts delays in its protocol, slowing down clients by forcing them to wait.
-   architecture astronauts
-   complexity merchants
-   SBOM: Software Bill of Materials
-   Heisenbug: Software bug that seems to disappear or alter its behavior when one attempts to study it.
-   [Bozo bit - Wikipedia](https://en.wikipedia.org/wiki/Bozo_bit)
-   embrace/extend/extinguish move
